More order, less searching

Everything in one place. And only you can get to it.

Plan a trip, collect paperwork, learn something, keep data in tables: Mumbin holds text, files, tables and tasks together and lets you decide which pages stay open and which only open with a password.

  • Arrange pages in a tree and link them – backlinks show what belongs together
  • Formatting while you type: headings, lists, tables, pictures – and any file as an attachment
  • Tasks live in your notes; the overview collects them by note, with start and deadline
  • Search with phrases, exclusions and tags – results come with a preview
  • Encrypt: a shared vault, a password of its own per page, or a sealed notebook
  • Notebooks are plain folders of text files – copy, back up, take along
  • An independent Python tool decrypts your data even without Mumbin
  • German and English, switchable without a restart
Features

From a loose note to your own web of knowledge

Everything you need to collect, organise and find things again – without a cluttered interface.

Write

Format as you write

Headings, bold, italic, lists and tables look like what they are right away. Only the line with the cursor shows the source. Drag pictures and files straight into the page.

  • Headings, bullets, task boxes, tables and code
  • Pictures and attachments by drag and drop, as a copy or a link
  • Format bar and shortcuts; Ctrl+Shift+P lists every command
Connect

Connect pages. See what belongs together.

Arrange pages in a tree with subpages and link them to each other. Backlinks show where a page is mentioned, and tags organise across the structure.

  • Links between pages, kept intact when you rename
  • Backlinks and a tag cloud below the page tree
  • Rename or move pages without breaking links
Find

Find what you wrote down

Search covers titles and text. Quotation marks find phrases, a minus excludes words, @tags or a page name narrow it down. Every hit shows a preview.

  • Phrases, exclusions, tags and page patterns can be combined
  • Ctrl+J jumps to any page in seconds
  • Locked content deliberately never shows up in results
Tasks

Tasks stay where they came from

Write a checkbox into a note – the task overview collects them all, grouped by note by default. One click ticks it off, a click on the text takes you back to the spot. Start and deadline are optional and set with a date picker.

  • Views: Open, Active, Waiting, Due, Done
  • Filter by words and @tags, switchable between grouped by note and one list
  • A date picker in the list and in the editor (Ctrl+Shift+D)
Notebooks

Several notebooks, each in its own folder

Switch between notebooks, open a folder or create a new one. Each notebook has its own settings: a page as the template for new pages, delete for good instead of the recycle bin, and automatic encryption of new pages.

  • One click switches notebooks; protected ones are unlocked when you open them
  • The template is an ordinary page of your notebook
  • The settings travel with the folder
Use

Tidy, quick and bilingual

The interface stays calm: one bar for formatting, a tree for navigating, one menu for everything else. Switch between German and English in the settings, instantly and without a restart.

  • Its own right-click menu in the text: Undo, Cut, Copy, Paste
  • Read-only mode, adjustable font size, a sidebar you can hide
  • Export a page, a branch or the whole notebook as HTML, or print
Protection & privacy

You decide what stays private.

Mumbin encrypts with Argon2id and XChaCha20-Poly1305. You choose the protection that suits your notebook – and you can mix them.

01

One password for many pages

The notebook's vault protects selected pages and their attachments with one passphrase. All other pages stay open.

02

A password of its own per page

Single pages get a password of their own, independent of the vault. Every page can have a different one – attachments included.

03

A sealed notebook

Everything is encrypted, including the names of pages and attachments on disk. The passphrase is asked for when you open it.

Privacy & control

Your files. Your decision.

Everything stays local

No account, no cloud, no telemetry. Your notes leave your computer only when you pass them on yourself.

Files, not a database

Unprotected pages are text files in a folder of your choice. Back them up, search them or version them with any tool.

Portable

One EXE and a folder. Settings sit beside it in mumbin_data, not in the registry. Copy everything to a USB stick or another PC.

A sealed-off interface

The interface loads no third-party content and blocks external requests. You open links on purpose, in your browser or the matching program.

Verifiable

The source code is publicly viewable. Automated tests cover the core, the interface and the real EXE – including encryption and attacks on file names.

An emergency exit

An independent Python tool decrypts your notebook with the right password, even if Mumbin is no longer around.

Your knowledge. Your way of working.

  • work personally on Windows and want to write offline too.
  • want to keep notes, documents, tasks and material in context.
  • look for local files and built-in password protection.
  • want to protect single pages with separate passwords.
FAQ

Good to know

What can I keep in Mumbin?

Formatted text, tables, pictures and any file as an attachment, for example PDFs, scans or spreadsheets. Everything stays in your notebook folder. Mumbin shows pictures and opens other files with the matching program.

Do I have to install anything?

No. Mumbin is a portable EXE: put it in a folder you can write to and run it. Settings are stored beside it in mumbin_data. It needs the Microsoft Edge WebView2 runtime, which many Windows PCs already have.

Does Mumbin send my notes to the internet?

No. The app stores notes locally and has no cloud connection and no telemetry. Links you click on purpose open your browser or the matching program. This website is served by GitHub Pages, independently of the app.

How secure is the encryption?

Mumbin derives the key from your password with Argon2id and encrypts with XChaCha20-Poly1305; if someone alters a file, decryption notices. The format is open: you can read it in the source code and in the Python tool.

Who owns my password?

Only you. There is no back door – so nobody but you can open your protected pages, not even the independent tool without your password. Keep it safe and back up your notebook folder.

Which protection should I choose?

For single confidential pages a password of their own is enough. The vault protects several pages with one key. If the names of pages and attachments should be hidden too, choose sealing when you create the notebook.

Will my notes stay readable if Mumbin disappears?

Unprotected pages are plain text files. You open protected pages with the included Python tool and your password – without Mumbin.

Can I use my notes on several PCs?

Yes: copy the notebook folder and the EXE, for example on a USB stick, or mirror the folder with a file-sync service of your choice. That way your notes are with you everywhere – without an account.

Can I export or print my notes?

Yes. A page, a branch or the whole notebook can be exported as HTML; pages can be printed. Unlocked protected pages appear in plain text in an export.

How do tasks work?

You write a checkbox into a note, optionally with a start and a deadline. The task overview collects all tasks of your pages, grouped by note or as one list.

Can I bring existing texts and files along?

Yes: paste texts straight into a page and keep files as attachments. Everything ends up in your notebook folder.
